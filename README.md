## Now

**Bréf** — a peer-to-peer, end-to-end encrypted messenger. No accounts, no phone
numbers, no server that sees who talks to whom. Peers find each other by public
key, punch through NATs, and fall back to a stateless relay only when they must;
an always-on desktop node holds the queue for when your phone is asleep.

Rust core over iroh · GTK4 on Linux and Windows · Jetpack Compose on Android.
Currently at design stage, deliberately before any code.

→ [Repository](https://github.com/daedaevibin/bref) · [Design spec](https://github.com/daedaevibin/bref/blob/main/DESIGN.md)

## Communication Protocol

I prioritize **clarity, atomicity, and technical rationale** in all interactions.

<ul>
  <li><b>Literal Interpretation:</b> I mean exactly what I write. Please avoid searching for "tone" or "subtext" in my messages, as I do not use them.</li>
  <li><b>Structured Contributions:</b> I prefer using GitHub Issues for bug reports and feature requests to maintain a searchable, permanent, and organized project history.</li>
  <li><b>Logical Directness:</b> I view direct feedback as a tool for efficiency, not as an act of hostility. If you find my phrasing blunt, please address the technical matter first—I value objective logic over emotional debt.</li>
</ul>
